# UniRide PWA — Angular 20

Prototipo académico para planificar viajes a los campus **Lima Norte (Puente Piedra)** y **Lima Sur (Villa El Salvador)** de la Universidad Autónoma del Perú. Creado por **Jhonn Pether**, Curso Electivo III.

> **Proyecto independiente / demostración:** no constituye una herramienta oficial de la universidad, no gestiona transporte real ni confirma servicios comerciales. Las tarifas mostradas son ejemplos.
